# Memory Matcher 🧠

A classic card-flipping memory matching game built with Python and Tkinter.

## Features
- Graphical card-flipping interface using Tkinter
- Randomized card positions every game
- Match detection and game state management
- Win condition tracking

## How to Run

1. Clone the repo
```bash
git clone https://github.com/kazmi1012/Memory-Matcher.git
cd Memory-Matcher
```

2. Run the game
```bash
python main.py
```

## Tech Used
- Python
- Tkinter (GUI)
- OOP (Object-Oriented Programming)
